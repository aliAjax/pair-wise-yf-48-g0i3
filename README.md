# pair-wise-yf-48 建筑设计竞赛匿名评审

源提示词摘要：主办方设置评分维度、权重和提交规则，评委在匿名状态下独立查看方案、打分、填写意见、声明利益冲突和保存草稿；系统提供提交进度、异常分处理、结果锁定与并列排名规则。

## 技术栈

Vue3、TypeScript、Vite、Naive UI、Pinia、Vue Router、Axios、VueUse、VeeValidate、Zod、Vue I18n。

## 共享评审台账（本机模拟服务端）

- 评委在本机给匿名方案打分；断网时可正常打分、写意见，修改暂存本机并标记“待同步”。
- 共享台账是独立的 localStorage 存储，原始写入遵循“后到的盖掉先到的”；两人同时提交同一方案时以后到者为准。
- 回网后按方案合并：仅本机改过的直接入账，仅台账改过的拉回本机；同一项两边都改过则保留两版，等评分本人确认，确认前该分不计入有效评委数与名次。
- 合并失败（离线或弱网）时本地草稿原样保留，可手动重试；侧边栏提供“弱网模拟”开关用于演示失败重试。
- 评分一改动，有效评委数与名次立即重算；结果按方案锁定，同分并列，重开某方案只让该方案自己的结果失效。
- 评委越权修改他人评分会被直接回绝并记入台账动态；主办方在锁定前看不到任何分值。
